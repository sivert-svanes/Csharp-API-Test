# Csharp-API-Test

A small ASP.NET Core Web API targeting .NET 9. It exposes a controller-based todo API backed by Entity Framework Core's in-memory provider, plus the default weather forecast example.

## Requirements

- .NET 9 SDK
- `curl` for the command-line examples below

## Run the API

From the repository root:

```powershell
dotnet restore Csharp-API-Test\Csharp-API-Test.sln
dotnet run --project Csharp-API-Test\Csharp-API-Test\Csharp-API-Test.csproj --launch-profile http
```

The HTTP profile listens on `http://localhost:5069`. An HTTPS profile is also available at `https://localhost:7299`.

The in-memory database is named `TodoList`, so todo items are lost when the application stops. IDs are generated by EF Core when items are created.

## API endpoints

The todo endpoints use the `/api/TodoItems` route:

| Method | Route | Result |
|---|---|---|
| `GET` | `/api/TodoItems` | Returns all todo items |
| `GET` | `/api/TodoItems/{id}` | Returns one item, or `404` if it does not exist |
| `POST` | `/api/TodoItems` | Creates an item and returns `201 Created` |
| `PUT` | `/api/TodoItems/{id}` | Updates an item and returns `204 No Content` |
| `DELETE` | `/api/TodoItems/{id}` | Deletes an item and returns `204 No Content` |

Todo request bodies use the following properties:

```json
{
  "name": "walk dog",
  "isComplete": true
}
```

For an update, include the matching `id` in the request body.

### curl

```bash
# Get all todo items
curl http://localhost:5069/api/TodoItems

# Get a todo item by ID
curl http://localhost:5069/api/TodoItems/1

# Create a todo item
curl http://localhost:5069/api/TodoItems \
    --header "Content-Type: application/json" \
    --request POST \
    --data '{"name":"walk dog","isComplete":true}'

# Update a todo item
curl http://localhost:5069/api/TodoItems/1 \
    --header "Content-Type: application/json" \
    --request PUT \
    --data '{"id":1,"name":"walk dog","isComplete":true}'

# Delete a todo item
curl http://localhost:5069/api/TodoItems/1 \
    --request DELETE
```

### PowerShell

Use `curl.exe` in PowerShell to call the native curl executable:

```powershell
# Get all todo items
curl.exe http://localhost:5069/api/TodoItems

# Get a todo item by ID
curl.exe http://localhost:5069/api/TodoItems/1

# Create a todo item
curl.exe http://localhost:5069/api/TodoItems `
    --header "Content-Type: application/json" `
    --request POST `
    --data '{"name":"walk dog","isComplete":true}'

# Update a todo item
curl.exe http://localhost:5069/api/TodoItems/1 `
    --header "Content-Type: application/json" `
    --request PUT `
    --data '{"id":1,"name":"walk dog","isComplete":true}'

# Delete a todo item
curl.exe http://localhost:5069/api/TodoItems/1 `
    --request DELETE
```

## Other development endpoints

- `GET /WeatherForecast` returns five generated weather forecasts.
- `GET /openapi/v1.json` serves the OpenAPI document while the app runs in the Development environment.

## Stack

| Type            | Technology              | Description       |
|-----------------|-------------------------|-------------------|
| Language        | C#                      | Statically typed language on .NET |
| Web             | ASP.NET Core Controllers | Controller-based Web API framework |
| Auth            | ASP.NET Identity Core   | It handles the user management side but isn't a token server on its own; for a Web API you typically pair it with JWT bearer authentication                  |                                  
| Auth**          | OpenIddict              | sits on top of Identity (or your own user store) and adds the actual OAuth2/OIDC endpoints                  |
| Database        | Postgres                | Just use postgres |
| Database Driver | Npgsql         | The .NET data provider for PostgreSQL; the underlying driver EF Core uses to talk to Postgres |
| ORM             | Entity Framework Core   | Object-relational mapping for .NET |
| Migrations **   | EF Core Migrations          | Built-in schema versioning; generates C# migration files from model changes and applies them |
| Audit Database ** | Audit.NET         | Library that records who changed what and when, with pluggable storage providers     |
| Docker          | what can be used        | Description of it |
